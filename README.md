# Web53 - Prácticas y Módulos Frontend

Repositorio que recopila diversas prácticas, ejercicios de desarrollo web frontend y consumo de APIs utilizando **HTML5**, **CSS3** y **JavaScript (Vanilla)**.

## Estructura del Proyecto

El proyecto está organizado de la siguiente manera:

```text
web53/
├── html/
│   ├── apiDog.html         # Consumo de API externa (The Dog API)
│   ├── bebidas.html        # Práctica interactiva de bebidas
│   ├── listaAlumno.html    # Visualización y filtrado de listas de alumnos
│   ├── practica02.html     # Ejercicio de maquetación y lógica con JS
│   └── preExamen.html      # Práctica de preparación para evaluación
├── js/
│   ├── bebidas.js          # Lógica para la gestión de bebidas
│   ├── leer.js             # Funciones para lectura de datos (JSON)
│   ├── preExamen.js        # Scripts de lógica para el pre-examen
│   ├── tabla.js            # Manipulación dinámica de tablas HTML
│   └── tablaPractica02.js  # Lógica de tablas para la práctica 02
├── alumnos.json            # Base de datos local en formato JSON
└── index.html              # Página principal de navegación

````
Tecnologías Utilizadas
HTML5: Estructura de las páginas web.

CSS3: Estilos y diseño responsivo.

JavaScript (ES6+): Lógica del cliente, manipulación del DOM y consumo de APIs asíncronas (fetch).

JSON: Almacenamiento y estructuración de datos locales (alumnos).

¿Cómo ejecutar el proyecto localmente?
Clona este repositorio:
```bash
git clone [https://github.com/KevinTorres-ui/web53.git](https://github.com/KevinTorres-ui/web53.git)
```
Abre la carpeta del proyecto en tu editor de código favorito.

Utiliza una extensión como Live Server en VS Code para abrir el archivo index.html en tu navegador, o simplemente abre el archivo directamente haciendo doble clic en él.
